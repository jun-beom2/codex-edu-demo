# 데이터루팀 — 출퇴근관리 화면 개선

> 📚 **이 저장소는 우신공업 Codex 활용 교육 7회차의 시연용 데모입니다.**
> 실제 사내 데이터·실명·거래처 정보는 들어있지 않으며, 가상 팀 4명의 가상 프로젝트입니다.
> 학습 목적으로만 사용하세요.

## 우리 팀이 하는 일

생산관리1팀의 일일 출퇴근 현황을 한 화면에서 보고, 야간조·연장근무 시간을 자동으로 집계합니다.
기존엔 엑셀 4개 파일을 사람이 합쳐서 부장님께 메일로 보냈는데, 이걸 **더블클릭 한 번**에 끝내는 게 목표입니다.

## 팀원

- 김출근 (생산관리1팀) — 팀장 · 출퇴근 화면
- 이근태 (생산관리1팀) — 야간·연장 집계
- 박야간 (생산관리2팀) — 부서별 요약
- 최주말 (인사총무) — 휴일 근무 표시

## 팀원 소개

> 각자 본인 PR로 자기 단락을 추가합니다 (7회차 PR 실습).

### 김출근 (팀장)

생산관리1팀에서 8년째 출퇴근·근태 데이터를 만지고 있습니다.
엑셀 4개 파일 합치는 일을 이번 분기에 끝내자는 마음으로 팀장 맡았습니다.
Codex는 5회차에 개인 도구 만들면서 익혔고, 팀 협업은 이번이 처음이라 같이 배워가요.

### 이근태

생산관리1팀, 야간조·연장근무 집계 담당입니다.
지금은 매일 새벽에 엑셀로 야간조 시간을 더하는데 자꾸 30분씩 어긋나서 화가 납니다.
이번에 야간/연장 자동 집계 화면 1개 만들어서 새벽 30분 돌려받는 게 목표예요.

### 박야간

생산관리2팀, 부서별 요약 화면 담당입니다.
2팀은 인원이 많아서 부서 단위로 한 번에 보고 싶다는 요구가 많았어요.
원래 코딩 한 줄도 안 해봤는데 5회차에 처음 만들어 본 도구가 동작하는 걸 보고 이번 팀에 합류했습니다.

## 작업 약속

1. `main`에 직접 commit 금지 — 반드시 `feat/{이름}-{내용}` 갈래로 PR.
2. PR 본문은 **프롬프트 5요소**(역할·맥락·형식·제약·예시)로.
3. 옆 팀원이 검토자 (Approve 받기 전엔 머지 X).
4. 회사 실데이터·실명·단가는 절대 commit하지 않는다.
